FAQ

Quick answers

Is it really free?

Yes. The plugin is free to download and use, and the source code is on GitHub.

Which heart-rate monitors work?

Anything the HypeRate app supports: Apple Watch, Wear OS, Garmin, Polar, ANT+/BLE chest straps and more. The plugin only needs your HypeRate ID.

Do I need browser sources or Streamer.bot?

No. This is a native OBS plugin written in C++. Everything renders directly inside OBS — no browser overlays, no external automation tools, no extra latency.

Horror games — what's the play?

Add Camera Shake + Glow to your facecam and a Threshold Toggle on a "PANIC" overlay at ~130 BPM. When the jumpscare lands, your whole stream feels it. Chat loves it.
